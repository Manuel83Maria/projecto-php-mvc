# projecto-php-mvc

## Requisitos
* PHP 8.2 ou superiot
*MYSQL 8 ou Superior
*Composer
## Como rodar o projecto baixado
instalar as dependencias
```
composer install
```
Verificar aBranch
```
gi branch
```
Baixar as actualizacoes
```
git pull
```
Adicionar todos os ficheiros na stagging area- area de prepafacao
```
git add.
```
Fazer o commit
```
git commit -m "mensagem do commit"
```
enviar os commit locais para o repositorio remoto
```
git push <remote> <branch>
git push origin dev-master
```
